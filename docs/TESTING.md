# 测试说明

测试时间：2026-10-15 · 环境：本地 dev（Next.js dev server）+ 真实数据源（扶摇 / iFinD / DeepSeek）

## 一、主链路测试（正向）

**输入**：内置样例 1（混合研报）

> 贵州茅台2025年半年报显示，营业总收入同比增长9.1%，归母净利润同比增长8.9%，加权ROE达17.9%。2025年10月9日贵州茅台收盘价为1384.8元。近日有消息称，贵州茅台与某头部新能源车企签署战略合作协议。从基本面看，公司品牌护城河深厚，长期投资价值突出。

**结果**（SSE 全流程，端到端约 40s）：

| # | 论断 | 判定 | 数据源实际 | 说明 |
|---|---|---|---|---|
| c1 | 营收同比 9.1%（2025H1） | ✅ 已核实 | 9.103244%（扶摇 financials，request_id 可回溯） | 偏差 <0.1% |
| c2 | 归母净利同比 8.9%（2025H1） | ✅ 已核实 | 8.891467% | 偏差 <0.1% |
| c3 | 加权ROE 17.9%（2025H1） | ✅ 已核实 | 17.89% | 偏差 <0.1% |
| c4 | 2025-10-09 收盘价 1384.8 元 | ✅ 已核实 | 1384.7988 元（扶摇历史K线，前复权） | 偏差 <0.01% |
| c5 | 茅台与新能源车企签署战略合作 | ✅ 已核实（存在性） | iFinD 资讯检索命中 5 条相关报道 | 仅存在性核实，非真实性认定 |
| c6 | 品牌护城河深厚/长期价值突出 | 🔵 观点 | — | 不做事实核验 |

验证点：SSE 流式输出、证据卡片（来源/时点/单位/口径/原始返回/request_id 齐全）、五色标签、统计面板。

## 二、数据缺失 / 无法核验（负向）

**输入**：内置样例 2（错误数据样本）中的「创年内新高」

- DeepSeek 将其拆为 `macro / CPI年内新高`，EDB 检索不到该"指标" → 返回 `无法核实`，理由"EDB 未返回该指标数据（指标名可能不匹配）"，**未猜测任何结论**。

其他覆盖：

- 主体无法定位：论断无股票名称且无代码 → `unverifiable`（"无法定位证券主体"）。
- 非交易日日期：历史收盘价查询命不中交易日 → `unverifiable`（"该日期无交易数据（非交易日或超出数据范围）"）。
- 财务论断缺报告期 → `unverifiable`（"缺少报告期（period），无法确定数据口径"）。
- 估值指标口径不匹配 → `unverifiable`（"估值摘要返回中未能定位该指标"）。

## 三、接口失败（负向）

设计行为（代码路径 `lib/fuyao.ts` / `lib/ifind.ts` / `lib/deepseek.ts`）：

- HTTP 非 2xx / 扶摇 code≠0（2001 无 key、2003 无权限、4001 限流）→ 该论断 `取证失败`，原因含 code 与 message，证据卡片保留原始返回。
- iFinD JSON-RPC error / 业务 code≠1 → `取证失败`，含 iFinD 错误信息。
- 网络超时（扶摇 20s / iFinD 60s / DeepSeek 90s）→ `取证失败`，DeepSeek 5xx 自动重试一次。
- DeepSeek 拆解整体失败 → SSE `fatal`，明确提示"拆解失败（不影响合规扫描结果）"，规则引擎扫描结果仍保留。
- 未配置密钥 → 直接返回"未配置"类 `取证失败`，不产生任何"核实"结论。

实测样例 2 中全部数据源调用均成功，失败路径由代码评审与上述设计保证；可用吊销密钥复现（`取证失败` 全覆盖，无静默"正常"）。

## 四、冲突检测（数值比对）

**输入**：内置样例 2（错误数据样本）

> 2025年9月CPI同比上涨2.5%，创年内新高…贵州茅台2025年上半年归母净利润同比增长25%，毛利率高达95%…

**结果**：

| 论断 | 判定 | 数据源实际 | 偏差 |
|---|---|---|---|
| 2025年9月 CPI +2.5% | ❌ 冲突 | -0.3%（2025-09-30，iFinD EDB，来源标注：国家统计局） | +933% |
| 归母净利同比 +25%（2025H1） | ❌ 冲突 | 8.891467%（扶摇） | +181% |
| 毛利率 95%（2025H1） | ❌ 冲突 | 91.2993%（扶摇） | +4.05% |

验证点：错误数值全部被捕获并展示 论断值 vs 实际值 vs 偏差率；CPI 附来源机构（国家统计局）与时点。

## 五、合规边界

**输入**：内置样例 3（违规样本）

> 这只票稳赚不赔，保本保收益，建议立即满仓买入，目标价3000元，涨停板近在眼前，错过再等十年，闭眼买入躺赢即可。

**结果**：命中 8 条合规发现——

- 规则引擎 3 条：收益承诺/保本表述、确定性买卖建议、夸大误导（各附监管依据：《证券法》第161条、《发布证券研究报告暂行规定》第12条、《适当性管理办法》）。
- LLM 复扫 5 条（细粒度句子定位）：稳赚不赔/保本保收益、建议立即满仓买入、目标价3000元、涨停板近在眼前、错过再等十年/躺赢。

**产品自身合规**：

- 输出仅为"论断与数据源是否一致"的核查结论 + 合规风险提示，全站无涨跌预测/收益承诺/买卖建议。
- 资讯存在性核实明确标注"存在性核实，非真实性认定"；未检索到时明确"未检索到 ≠ 不成立"。
- 页面显著位置放置免责声明；导出报告含免责声明。
- 人工复核闭环：每条结论可「确认无误 / 驳回（填理由）」，审计留痕随报告导出。
